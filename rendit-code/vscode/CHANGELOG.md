# Changelog — RenDit Code IntelliSense

## 0.3.0

- `className=""` сразу показывает все классы; после пробела (между классами) список, наоборот, не открывается.
- Ранжирование стало умным: префикс выше подстроки, подстрока выше подпоследовательности. `p` → сверху `p-*`, `pb-*`, ниже `gap-*`, `opacity-*`; `pb` → только `pb-*`.
- Поиск по CSS-свойству: `padding` / `padding-bottom` → `pb-*`.
- Добавлены тесты (`node --test test/`): ранжирование, описания классов, полный цикл автодополнения.

## 0.2.0

- Подсказки больше не открываются просто по пробелу: они ждут первую букву, а после варианта (`hover:`, `md:`) показывают классы.
- У каждого класса в списке — короткое описание: `pb-4` → `padding-bottom: 4px`. Варианты подписаны (`hover:` → `:hover`, `md:` → `@media (width >= 770px)`, `dark:` → «тёмная тема»).
- Поиск по CSS-свойству: вводишь `padding` или `padding-bottom` — подсказывается `pb-*` (класс можно и не помнить).
- Проверка классов `renditCode.validateClasses` теперь работает: слушает открытие, изменение и сохранение документов.
- Код разложен на модули (`src/`), описания и CSS — чистые функции, которые можно тестировать в Node.

## 0.1.0

- Добавлены подсказки классов и вариантов RenDit Code.
- Добавлены CSS при наведении, образцы цвета и необязательная диагностика неизвестных классов.
